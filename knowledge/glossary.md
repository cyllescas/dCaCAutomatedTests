# Glosario funcional

| Término | Definición documentada |
| --- | --- |
| AEP | Plazo calculado según los días que un comprador suele demorarse en pagar. |
| Admin | Usuario administrativo, generalmente asociado al perfil o permiso 4. |
| CI / CID | Compra Inmediata o Compra Dinámica enviada a posibles compradores de una tropa. La fuente usa ambas siglas para el mismo flujo. Confirmar denominación oficial. |
| Comercial Regional (CR) | Perfil administrativo asociado a sociedades, generalmente con permiso 6. También se lo denomina Asociado Comercial. |
| Condiciones pactadas | Datos de una cotización aceptada que deben copiarse al legajo de la tropa. |
| Cotización | Propuesta enviada al vendedor para adquirir su tropa. Su aceptación implica que la tropa fue vendida. |
| Desbaste | Peso o porcentaje de peso que se espera que pierdan los animales. |
| Encierre | Condición previa al pesaje: 24 horas, tarde anterior o sin encierre. |
| Faena | Operación vinculada con animales destinados a faena. |
| Invernada | Operación vinculada con invernada o cría. |
| Legajo | Registro de una tropa donde se consolidan sus condiciones y datos operativos. |
| MAG | Mercado Agroganadero, también llamado Mercado de Cañuelas. |
| ONCCA | Dato numérico requerido por la configuración documentada para habilitar una sociedad como compradora de directo. |
| Representante | Perfil con vista equivalente a la de un cliente, asociado a usuarios y sociedades. |
| Sociedad | Entidad a la que se vinculan usuarios y capacidades de compra, venta o transporte. |
| Tabla | Precio determinado por kilogramo dentro de una cotización de invernada. |
| Tabla desde | Peso mínimo desde el cual comienza a aplicarse el precio por tabla. |
| Tabla menos | Importe aplicado por kilogramo excedente en el rango documentado entre “Tabla desde” y “Tope”. La fórmula exacta debe confirmarse. |
| Tope | Peso máximo definido en una cotización de invernada. |
| TP2 | Porcentaje del valor de la operación tratado bajo una condición especial de pago. La fuente lo describe como pago “en negro”; requiere definición formal. |
| Tropa | Lote de animales ofrecido y gestionado en una operación. |
| VI | Viaje Inmediato. |
