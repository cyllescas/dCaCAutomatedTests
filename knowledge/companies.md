# Sociedades

## Capacidades y habilitaciones

### Sociedad vendedora

- `BR-SOC-001`: puede vender invernada o faena.

### Compra de invernada

- `BR-SOC-002`: todas las sociedades pueden ofertar por tropas de invernada según la fuente.
- `BR-SOC-003`: para comprar mediante Compra Inmediata de Invernada debe estar activo `Es sugerido para Compra Inmediata de Invernada`.
- `BR-SOC-004`: cualquier Admin puede editar esa habilitación.
- `VAL-SOC-001`: la activación no requiere cargar datos adicionales.

### Compra de faena

- `BR-SOC-005`: para ofertar por una tropa de faena y verla en la home debe estar activo `Esta sociedad es compradora de directo`.
- `VAL-SOC-002`: esa activación requiere algún nombre en `Matrícula` y un número en `ONCCA`.
- `BR-SOC-006`: para comprar faena debe estar activo además `Es sugerida para compra inmediata de faena`.
- `BR-SOC-007`: cualquier Admin puede editar ambas habilitaciones.

### Transporte

- `BR-SOC-008`: para operar como transportista debe estar activo `Esta sociedad es transportista`.
- `BR-SOC-009`: cualquier Admin puede editar esa habilitación.

## Creación de sociedades

### Desde Admin

`FL-SOC-001`: `Datos` → `Gestión de sociedades` → `Crear Sociedad`.

### Desde cliente

`FL-SOC-002`: `Perfil` → `Mis Sociedades` → `Nueva sociedad`.

### Desde representante

`FL-SOC-003`

1. Ir a `Clientes`.
2. Seleccionar `Ver perfil`.
3. Entrar a `Mis Sociedades`.
4. Seleccionar `Nueva sociedad`.

Los dos últimos pasos coinciden con la creación desde cliente.
